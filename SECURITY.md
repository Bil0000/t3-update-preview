# Security

This tool can replace application files and restart services. Treat an unverified release or an unexpected update target as a reason to stop.

Report a suspected vulnerability through [GitHub private vulnerability reporting](https://github.com/Bil0000/t3-update-preview/security/advisories/new) when that feature is enabled. If the form is unavailable, open an issue that asks for a private contact method. Do not include exploit details or sensitive data in that public issue.

Include the updater version, operating system, affected code path, expected result, and steps that reproduce the issue in an isolated fixture. Do not send credentials, private device addresses, complete configuration files, session databases, or personal backups.

There is no guaranteed response time or long-term support policy. Fixes will be documented in the changelog. Do not assume that older releases receive security fixes.
